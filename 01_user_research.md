# Basic User Research

## Target Users
College students and trainees who need to keep track of assignments, deadlines, and task status.

## User Needs
1. See upcoming and overdue tasks quickly.
2. Understand what each task requires.
3. Mark work as completed.
4. Find task details without navigating through many screens.
5. Receive a clear visual indication of overdue work.

## Common Pain Points
- Forgetting assignment deadlines.
- Too much information on one screen.
- Difficulty distinguishing completed and pending work.
- Unclear task instructions.

## Design Opportunity
Create a simple mobile task manager with a dashboard, clear status labels, task details, and a straightforward completion action.
