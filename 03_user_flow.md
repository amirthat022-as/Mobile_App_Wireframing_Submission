# User Flow

```text
[Open App]
     |
     v
[Login / Continue]
     |
     v
[Dashboard]
  |       |
  |       +--> [Completed Tasks]
  |
  v
[Select Task]
     |
     v
[Task Details]
  |       |
  |       +--> [Back to Dashboard]
  |
  v
[Mark Complete]
     |
     v
[Task Completed]
     |
     v
[Dashboard]
```

## Primary Flow
1. User opens the app.
2. User reaches the dashboard.
3. User selects a task.
4. User reads the task details.
5. User marks the task complete.
6. Dashboard updates the task status.
