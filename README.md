# Mobile App Wireframing Submission

## Project
Low-fidelity wireframes for a simple **Student Task Manager** mobile application.

## Included
- `01_user_research.md` — basic user research and needs
- `02_user_persona.md` — primary user persona
- `03_user_flow.md` — main user flow
- `04_design_thinking.md` — design thinking process
- `wireframes.svg` — low-fidelity mobile wireframes
- `wireframes.html` — browser preview of the wireframes

## Main Flow
Login → Dashboard → Select Task → View Details → Mark Complete

The design intentionally uses simple grayscale blocks and labels to represent an early-stage wireframe rather than a final visual design.
