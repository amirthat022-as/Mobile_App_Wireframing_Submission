# Design Thinking Process

## 1. Empathize
Consider the needs of students managing multiple assignments and deadlines.

## 2. Define
Students need a quick way to understand what is due, what is overdue, and what has been completed.

## 3. Ideate
Possible solutions:
- Task dashboard
- Due-date labels
- Overdue indicator
- Task detail screen
- One-tap completion action

## 4. Prototype
Create grayscale, low-fidelity screens before investing in visual styling.

## 5. Test
Ask users to:
- Find an overdue task.
- Open its details.
- Identify the due date.
- Mark the task complete.

## Expected Learning
Early wireframing helps validate information hierarchy and user flow before visual design and development.
